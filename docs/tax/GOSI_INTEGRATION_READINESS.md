## 3. REQUIRES_VERIFICATION register (the official-format items)

Every detail that could NOT be verified against an official GOSI publication in this environment
(gosi.gov.sa is unreachable from the sandbox — the fetch attempts + the honest note are recorded
in every seeded verification record). None of these blocks the export (the mitigation is in code);
each is a PHASE-055 resolution item, to be listed in the statutory verification register
(`docs/decisions/product/STATUTORY_VERIFICATION_REGISTER.md` — the seeded-rows register that
lands with T-15 in the W-7 docs wave).

| # | Spec detail | Why it could not be verified | Status | Mitigation delivered (PHASE-046) |
|---|-------------|------------------------------|--------|----------------------------------|
| RV-1 | **The official GOSI submission file format** (the SADAD/edfa3 upload schema, its field set, encodings, and validation rules) | No official format specification was reachable to pin; the export therefore states the platform's own reconciliation-grade schema (the contribution breakdown per employee + the summary block), labeled as a statement — never as a GOSI-formatted file | REQUIRES_VERIFICATION (resolves in PHASE-055 against the official spec) | The export's schema is fully self-describing (bilingual headers, the summary block, the footer); the parse-back round-trip spec pins it; a future official-format adapter composes over the same frozen data, never a rewrite |
| RV-2 | **The employee identifier GOSI requires in a submission file** (national ID / iqama semantics and masking rules in files at rest) | No official field specification; the platform's PII discipline (the payslips precedent) forbids exporting unmasked `national_id` without a verified requirement | REQUIRES_VERIFICATION (resolves in PHASE-055) | The export carries the employee CODE + name pair only; `national_id` and bank fields never leave through it |
| RV-3 | **The SANED-specific 15,000 wage ceiling** | The PwC citation (the GOSI family's closed source) states the 45,000 ceiling on basic + housing but NOT the SANED-specific 15,000 figure; the owner's confirmation is pending | REQUIRES_VERIFICATION (the register's standing open item) | The ceiling ships as DATA on the seeded row with the review note; a correction is a data change through the verification discipline, never a code change |
| RV-4 | **The establishment-number field semantics** (which GOSI identifier the submission actually requires — establishment vs branch numbers) | No official submission spec (RV-1) | REQUIRES_VERIFICATION (resolves in PHASE-055) | The setting carries ONE tenant-level establishment number, honestly labeled; unset renders the not-configured note |

Register rules: a REQUIRES_VERIFICATION item never silently becomes verified — the resolving
phase records the official source and evidence in the statutory verification register and flips
the row with a dated note (the GCC_EINVOICING_READINESS precedent).

## 4. The delivery laws (binding on every future wave)

1. **BR-086 — the export is a read-only audited artifact**: no register reads, no journal writes,
   no new machinery; every generation is an audit event. The W-4 route-level spec pins the
   negative ledger proof (the run row + the journal registers byte-identical through every
   export).
2. **The frozen-snapshot law**: the export renders the run's FROZEN statutory data (the line
   breakdowns + the `statutory_summary` + the run columns) — it never recomputes, never
   re-resolves profiles, never rounds (INV-032's exact 4dp strings ride the file untouched).
3. **POSTED-only**: only a posted run carries the frozen liability a remittance file states
   (the G-52 settlement's own law); anything else is the typed refusal.
4. **The totals tie is asserted in service code**: Σ per profile row of the export rows must
   equal the frozen summary's accruals — a malformed file cannot leave the service.
5. **PHASE-055 is the only path to live integration**: any adapter lands there, behind its own
   gates; nothing in the payroll module may gain an outbound HTTP client to any authority.
