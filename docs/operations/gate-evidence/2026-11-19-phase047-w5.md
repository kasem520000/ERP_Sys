## 5 — The honest disclosure: a PRE-EXISTING 045 defect the wave's component tests caught (the self-board Tabs finding — recorded, NOT fixed here)

While landing the W-5 boards I reproduced, in a minimal in-session jsdom
proof (the mechanism below — reproducible from the shipped tree at any
time; no kept artifact, the mechanism IS the proof), a **latent
rendering defect in the 045 `/hr/self` surface**
(`hr-self-board.tsx`):

- **The mechanism:** the `@erp/ui` `Tabs` component maps its children
  through `Children.forEach`, assigning the LAST child to the
  `unslotted` slot; React's traversal converts a falsy child to
  `null`, so a conditional-expression children array
  (`{tab === "a" && <div/>}{tab === "b" && <div/>}`) ends with
  `unslotted = null` **whenever the active tab is not the LAST
  expression** — the content branch never renders.
- **The blast radius (verified against the shipped tree):**
  `hr-self-board.tsx` is the ONLY surface using the conditional shape
  (the 046 eosb/statutory boards use the `data-slot` shape; the other
  045 boards don't use Tabs at all). **The self-service screen renders
  only its LAST tab's content ("roster"); the "attendance" and "leave"
  tabs render empty** — the tab headers switch but the content area
  stays blank.
- **Why no one caught it:** the 045 wave shipped no component tests
  for the self board (the atp-promise-point pattern landed with 046),
  and the wave's visual verification pass hit the roster tab's
  neighborhood — the defect is invisible at the route level (200, no
  console error — the DOM is simply empty).
- **The W-5 boards are immune BY CONSTRUCTION:** all four use the
  `data-slot` shape (the eosb/statutory precedent — the shape this
  wave's 35 component tests render through).
- **The repair (3 lines, recorded for the owner's dispatch):** wrap
  the self board's three tab bodies in `data-slot` divs (exactly the
  eosb shape) + one component test proving the first tab renders. It
  is 045 scope — per the one-phase law (red line 1) this wave does NOT
  touch it; the owner dispatches (a standalone maintenance repair in
  the 029 pattern, or folded into another vehicle at their choice).
