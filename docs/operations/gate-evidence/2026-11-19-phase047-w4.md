## 4 — The NF-9/NF-10/NF-11 fixes (the owner's W-3 verification findings, delivered with this wave)

- **NF-9 (the LIKE wildcard hole — the mandatory code fix)** —
  `moveOrgUnit`'s descendant match is now
  `starts_with(path, ${oldPath} || '.')` — LITERAL prefix semantics.
  The W-3 shape `path LIKE ${oldPath}.%` carried a real hole (proven by
  the owner on a live cluster): org codes legally contain the
  underscore (ORG_CODE_RE) and `_` is a single-character wildcard in
  LIKE, so the pattern `SALES_EAST.%` matched BOTH `SALES_EAST.child`
  AND `SALESXEAST.otherchild` — a sibling tree whose code matched at
  the underscore position would have its path corrupted by the move.
  The fix is the owner's specified alternative (starts_with), and the
  **adversarial close-code arm (d4)** pins it in
  `talent-training-org.db.spec.ts`: the pair `ADV{seq}_EAST` vs
  `ADV{seq}XEAST` (identical except the underscore position), the move
  rewrites ONLY the moved tree's descendants — the sibling's subtree
  path, parent, and version are UNTOUCHED. The dated note rides the
  store header.
- **NF-10 (the phantom hire arm — the documentation fix, delivered as
  the owner's PREFERRED remedy)** — the written-once arm exists for
  real: `casAdvanceStage`'s WHERE now carries
  `AND (${hiredEmployeeId}::uuid IS NULL OR hired_employee_id IS NULL)`
  — active only when the statement carries a hire link, vacuously true
  for every ADVANCE/REOPEN call. The store header's `casHireApplicant`
  misnomer is corrected (the header now names the real function and the
  real arm, with the dated NF-10 note recording what the W-3 shape
  was); both service doc sites (the header's HIRE ACT law + the
  `hireApplicant` docblock) now state the TWO defense lines truthfully.
  The **store-level arm (d2)** pins the deeper law: a row pinned at
  OFFER but ALREADY LINKED (a state no API path produces — the raw
  seed) matches ZERO rows with ZERO residue (version unbumped, no HIRE
  history record, the original link intact).
- **NF-11 (the unit count)** — the dated 58 → 59 correction rides the
