## 1 — The pure layer FIRST (§4's unit-first law — and it caught the spec's own hand-slip)

  fold never trusts the writer for its arithmetic).
- **`overlapMs` / `elapsedMs`** — the window-clamped subtraction: (end −
  start) minus every pause interval's overlap with the window, never
  negative; an interval outside the window subtracts NOTHING (the
  mathematical floor, no special cases).
- **`evaluateSlaClocks`** — THE SINGLE evaluation both clocks read: the
  response window [dispatched, firstResponded ?? now] and the resolution
  window [dispatched, completed ?? now], each minus its own clamped pause
  overlap; `targetMs: null` is the honest NO_TARGET absence (the register
  unset — fail-closed, never a fabricated target, red line 5); breach is
  strict (AT target is within).
- **`escalationDecisions`** (BR-096, pure): the breached-with-target clocks
  with their once-per-event dedupe keys (`fieldservice-sla-breach:{visit}:
  {clock}` — a clock's elapsed only grows until it freezes, so a breach is
  permanent; the key proves the single escalation).
- **`hoursToMs`** — the register's single conversion, in EXACT decimal
  (`new Decimal(hours).times(3_600_000)`) with Number() only at the
