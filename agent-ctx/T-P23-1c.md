## Binding mechanics applied

1. **Key material never in the registry table** — the certificate row stores the
   secret-store PATH + metadata only; the encrypted blob lives in the files module.
2. **Audit entityId must be a UUID** — the purge hook's audit rows use real entity ids
   (the first draft's string label `tenant-purge` failed the audit constraint; lesson:
   delete-flow audits name the entity, not the operation).
3. **FK order on purge** — certificate deletion removes usage rows first (the FK chain),
   and the definer grant includes DELETE on the usage table (purge is the only writer).
4. **Rollout flags default OFF** — asserted; the T13 gate means the ZATCA stub stays
   dark for every tenant until an admin enables it with a provisioned cert.
