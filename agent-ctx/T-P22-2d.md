## Binding mechanics applied

1. **§3.5 clause mapping** (documented in channel-port.ts): caller resolves locale+template
   before the call; port receives the resolved payload; implementor owns retry + quota;
   best-effort results never throw.
2. **Storage decision (DR-P22-07a):** no natural devices JSON column (capabilities =
   feed-scoping slice; trust_flags = audited admin plane) → dedicated `device_push_tokens`
   table via 0034 — platform plumbing, opt-in explicit, default OFF.
3. **No financial payloads:** the adapter whitelist + template content + test assertions
   (three layers).
4. **Disabled mode:** FCM credentials unset → DisabledFcmTransport (skeleton-honest; the
   real credentials are CI secrets placeholders — handoff to 4-a).
