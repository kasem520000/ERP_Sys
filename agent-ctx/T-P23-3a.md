## Binding mechanics applied

1. **Parking discipline (BR honesty):** an unparseable row parks with its RAW cells and
   a reason — the system never invents an amount; resolution is a human decision recorded
   as `resolved_line_id`.
2. **Commerce natural-key upsert:** `(tenant_id, channel_adapter_id, channel_order_id)`;
   conflicts are SERVER-DECISION with `conflict_detail` (no LWW); batch Idempotency-Key
   + cursor before/after recorded per import.
3. **Create/complete split for the platform probe** — the import flow's platform check
   runs on its own connection and must see COMMITTED data (the same lesson as the
   checkout webhook flow): creation and completion are separate committed units.
