## Binding mechanics applied

1. **State machine legality:** every transition is table-driven and asserted; the
   `applyOutcome` fix — a GENERATED row transitions to SUBMITTED and the final outcome
   lands on the same row (the first draft lost the terminal outcome by returning early).
2. **Artifacts:** payload/response bytes never touch the DB — encrypted blobs via the
   files module (`einvoicing/{jurisdiction}/{tenant}/…`); the spec proves
   `application/octet-stream` + decrypts back to the compliance archive.
3. **Idempotency:** one registry row per (document × adapter); the retry chain appends
   attempts (`attempts`, `next_attempt_at`, `retry_of_submission_id`) without violating
   the partial unique (live states only).
4. **Fingerprint stability:** JSONB key-order independence — the digest is computed over
   a canonicalized shape, not the raw serialization (PostgreSQL reorders JSONB keys).
