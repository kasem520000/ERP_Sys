## Decisions / deviations (for the completion-report DR ledger)

- **D1 (revocation return shape — ALIGNED this pass)**: the task mandates
  `purgeOnRevocation(store): PurgeReport`; the first incarnation returned
  `{ purged: PurgeReport }`. This pass aligned it to the mandated
  signature (the wrapper added nothing; no other consumer existed —
  verified by a repo-wide search). `PurgeOnRevocationResult` is GONE from
  the module + barrel; host/revocation tests updated.
- **D2 (triggers option names — ALIGNED this pass)**: the task mandates
  `timers?: { setInterval, clearInterval, setTimeout, clearTimeout }` +
  `now?: () => number`; the first incarnation had four separate
  `*Fn` options + `clock`. This pass renamed/repacked them into the
  mandated `SyncTriggersOptions` shape; `globalSyncTimers` (the default
  suite) is exported for the shell. The public `now()` diagnostic stays.
- **D3 (D-01 purge scope — implemented exactly per the doc)**: §6.2 "purge
  local tenant data (outbox included — its commands are already
  server-rejected by policy) and require online re-login". Every
  `DESKTOP_BUSINESS_TABLES` row + outbox + inbox mirrors + cursors
  emptied; **local_events rows KEPT with payload CONTENT scrubbed to
  NULL** — the audit trail is "kept forever, never pruned" (LOCAL_DATABASE
  §5.2 exclusion, cited in the module header) while the payload column is
  tenant business data (§6.2), so facts survive, content does not; both
  counts are reported honestly (`localEventsKept` +
  `localEventsPayloadsScrubbed`).
- **D4 (meta scope of the purge)**: deletes `enrolledDeviceId` +
  `permissionSnapshotAt` (the task's named keys) PLUS `queueUnresolvable`
  — a stale unresolvable flag would block the re-enrolled device's drains
  via `nextBatch` forever (cycle.ts's `markQueueUnresolvable` semantics);
  deleting it is required for "machinery STRUCTURE intact + reusable".
  `contractVersion`/`deviceClass`/`rolloutChannel` STAY (LOCAL_DATABASE
  §2: the store's compiled-in floor, never the server's version);
  `cursorCount`/`inboxCount` recomputed so the next `recoveryPass` is
  clean (tested).
- **D5 (revocation wiring = the host, not the cycle)**: the task's "session
  .onRotationFailure + status.device.revoked + outcome.deviceRevoked all
  lead to: stop syncing (phase 'revoked'), then purge" is implemented as
  the host's `onRevocation` hook — the host STOPS (`markQueueUnresolvable`
  mirrors cycle.ts; every later syncNow/pushNow returns
  `{skipped:"revoked"}` until re-enrollment constructs a fresh host) and
  the SHELL runs `purgeOnRevocation` + `host.recordRevocationPurge(report)`
  (the destructive purge stays a first-class audited step). The D-01
  seam additionally covers `status.device.dataExpiresAt` past server time
  (§6.2 remote data-expiry — SECURITY doc §6.2, tested). `requireReenroll-
  ment` = the phase-2b UI path: 2-b renders `phase:"revoked"` + the
  re-enroll screen. `handleRotationFailure(NO_CREDENTIAL)` is
  deliberately NOT a revocation (never enrolled / already purged) — the
  session-expired path owns that state; only `ROTATION_FAILED` (the M-05
  reuse signal) is terminal.
- **D6 (4th test file)**: `sync-transport.test.ts` (18 tests) pins the

## The EXACT API surface for 2-b (web console) + the shell

```ts
// ── HostState (the UI mirror 2-b renders; emitted on EVERY transition) ──
interface HostState {
  readonly phase: "idle" | "syncing" | "read-only" | "revoked" | "corrupt" | "error";
  readonly lastOutcome?: CycleOutcome;     // from @erp/sync-core {pulled,pushed,accepted,rejected,deferred,duplicates,readOnly,deviceRevoked,durationMs}
  readonly lastSyncAt?: string;            // ISO
  readonly lastError?: string;             // undefined = clean
  readonly readOnlyReason?: "CONTRACT_VERSION_UNSUPPORTED"; // exactly when phase==="read-only"
}

// ── SyncDesktopHost ────────────────────────────────────────────────────
constructor(opts: {
  store: DesktopStore;                     // OPEN, fully migrated (openDesktopStore)
  transport: SyncTransport;                // bridgeTransport in the shell
  session: DesktopSession;                 // from src/auth
  deviceId: string;                        // the enrolled device id (x-device-id)
  onState?: (state: HostState) => void;    // the 2-b mirror subscription
  onUpdatePrompt?: (reason: "CONTRACT_VERSION_UNSUPPORTED") => void; // ONCE per gate trip
  onRevocation?: (detection: RevocationDetection) => void; // D-01: shell purges + re-enrolls
  prune?: { budgetBytes?: number };        // DR-P21-03 post-cycle; default 1 GiB
})
get state(): HostState;  get lastPurge(): PurgeReport | null;
get lastPrune(): DesktopPruneResult | null;  get lastPruneError(): string | null;
get readOnlyReason(): "CONTRACT_VERSION_UNSUPPORTED" | undefined;
canWrite(): boolean;           // 2-b gates draft forms: false while read-only/revoked/corrupt
queueDepth(): number;          // QUEUED + IN_FLIGHT (§8 "while dirty")
queueStats(): OutboxQueueStats;// {pending,inFlight,rejected,acked} — engine queueStats
boot(): Promise<SyncCycleResult>;          // full runCycle (recovery inside, §3)
syncNow(): Promise<SyncCycleResult>;       // {outcome} | {skipped:"already-running"|"revoked"}
pushNow(): Promise<PushNowResult>;         // push-only fast path | {skipped}
handleRotationFailure(failure: RotationFailure): void; // wire into DesktopSession onRotationFailure
recordRevocationPurge(report: PurgeReport): void;      // after the shell's purge

// ── SyncTriggers (§8) ───────────────────────────────────────────────────
constructor(opts: {
  host: SyncDesktopHost;
  bridge: Pick<DesktopBridge, "connectivity"> | null;
  timers?: SyncTimers;   // {setInterval,clearInterval,setTimeout,clearTimeout} — default globalSyncTimers
  now?: () => number;    // default Date.now
})
start(): void;                    // arm connectivity subscription + 2-min timer (idempotent)
onStartOrUnlock(): Promise<void>; // → host.syncNow (full cycle; recovery inside)
onLocalWrite(): Promise<void>;    // → host.pushNow (push-only, NO pull)
onManualSync(): Promise<void>;    // → host.syncNow
now(): number;                    // diagnostics
stop(): void;                     // cancel ALL (idempotent; restartable)

// ── purgeOnRevocation (D-01) ────────────────────────────────────────────
purgeOnRevocation(store: DesktopStore): PurgeReport;
interface PurgeReport {
  readonly tables: Readonly<Record<string, number>>; // per-table deleted rows (exhaustive)
  readonly localEventsKept: number;                  // audit rows survive (§5.2)
  readonly localEventsPayloadsScrubbed: number;      // payload content nulled
  readonly metaKeysDeleted: string[];               // enrolledDeviceId, permissionSnapshotAt, queueUnresolvable
  readonly metaKeysKept: string[];                  // honest remainder (contractVersion stays)
  readonly purgedAt: string;                        // ISO
}
REVOCATION_PURGED_TABLES; REVOCATION_DELETED_META_KEYS;

// ── transport ───────────────────────────────────────────────────────────
bridgeTransport(opts: {
  bridge: Pick<DesktopBridge, "http">;
  baseUrl: string;                        // API origin; trailing slashes normalized
  session: { current(): string | null }; // read FRESH per request; null ⇒ DesktopSessionExpiredError (zero bridge calls)
  deviceId: string;                       // x-device-id
}): BridgeTransport;                       // SyncTransport + guaranteed status/pushV2/pullAck/pushAck
DesktopSessionExpiredError (code DESKTOP_SESSION_EXPIRED);
DesktopSyncHttpError { status, body, url };   // non-2xx
DesktopSyncResponseError { url };            // non-JSON / non-envelope / schema-failing
DEVICE_ID_HEADER, SYNC_STATUS_PATH, SYNC_PULL_PATH, SYNC_PUSH_PATH, SYNC_PULL_ACK_PATH, SYNC_PUSH_ACK_PATH
```

## The shell boot order (2-c consumes this; MASTER-PLAN §3 + §5)

```
openDesktopStore({ path, encryptionKey?, profile? })   // 1-a: open + migrations v1–5
  → construct DesktopSession({ getRefreshToken, refresh, onRotationFailure:
        (f) => host.handleRotationFailure(f) })         // late-bound closure — see below
  → bridgeTransport({ bridge, baseUrl, session, deviceId })
  → new SyncDesktopHost({ store, transport, session, deviceId, onState, onUpdatePrompt,
        onRevocation: (d) => { /* stop triggers */; const report = purgeOnRevocation(store);
                                host.recordRevocationPurge(report); /* show re-enroll screen */ },
        prune })
  → new SyncTriggers({ host, bridge, timers?, now? })
  → triggers.start()
  → triggers.onStartOrUnlock()   // = host.boot(): runCycle step 1 IS the recoveryPass
```
Note the late binding: the session's `onRotationFailure` closes over the
host, so construct the session AFTER the host reference exists (or wire
via a mutable holder) — the D-01 path then flows
session → host.handleRotationFailure → phase "revoked" + onRevocation →
shell purge + re-enroll UI.
