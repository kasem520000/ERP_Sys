## Binding mechanics applied

1. **Driver seam (DR-P22-01):** sync signatures on the port; the expo-sqlite device driver
   bridges internally (documented strategy in driver-port.ts for the native author);
   node-driver is the test + chaos-harness driver — real SQLite files, real WAL.
2. **Personal profile (DR-P22-08b):** `applyPersonalMigrations` creates cursors + meta +
   personal read models ONLY — sync-core's `applyMigrations` is NOT called for personal
   because its v1 bundles outbox creation with cursors (LOCAL_DATABASE §1.1 rule 2 quoted
   in migrations.ts comments); personal cycles are pull-only via SyncClient.pullAll and
   the host hard-guards pushAll unreachable for the personal class.
3. **Budgets:** byte counting on serialized payloads in the transport guard (8 MB pull /
   2 MB push from constants; 256 KB personal background) — correctness never depends on a
   cycle completing (budget exhaustion splits across cycles).
4. **Contract gate + revocation:** C-08 CONTRACT_VERSION_UNSUPPORTED → read-only mode +
   update prompt callback; D-01 → purge (outbox+inbox+read models for personal) + re-login.
